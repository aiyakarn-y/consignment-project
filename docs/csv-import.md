# นำเข้ารายงาน CSV

1. เปิด ตั้งค่า / ประวัติ → รูปแบบนำเข้า แล้วเลือกไฟล์ตัวอย่าง `.csv`
2. อ่านชีตและหัวตาราง (CSV แสดงเป็นชีตชื่อ `CSV`)
3. จับคู่คอลัมน์ SKU/รหัสอ้างอิง จำนวน ราคา/ยอดขาย ลูกค้า และส่วนลดตามข้อมูล
4. ดูตัวอย่าง Mapping แล้วบันทึกรูปแบบ
5. เลือกรูปแบบที่บันทึกไว้ในช่องรูปแบบสำหรับ Import แล้วนำเข้า CSV

รองรับ UTF-8 (มีหรือไม่มี BOM), UTF-16 พร้อม BOM และ Windows-874
ตรวจตัวคั่น comma, semicolon และ tab อัตโนมัติ รองรับข้อความในเครื่องหมาย
คำพูดและข้อความหลายบรรทัด เก็บเลขศูนย์นำหน้า SKU โดยไม่แปลงเป็นตัวเลข
หากตรวจคอลัมน์ไม่ตรงกับต้นฉบับ ให้บันทึกไฟล์เป็น CSV UTF-8 แบบ comma
และดูตัวอย่างใหม่ก่อนนำเข้า

สูงสุด 25 MB ต่อไฟล์, 50,000 แถว, 200 คอลัมน์ และ 1,000,000 ช่อง
CSV ไม่มีการเดาความหมายราคา/ส่วนลดจากหัวคอลัมน์ ต้องใช้ Mapping ที่ยืนยันแล้ว
ไฟล์ Export ยังคงเป็น Excel ตาม Consign_sample.xlsx
